# Screen effect screenshots

In-game screenshots for the preview box on Pocket Encore's **Effects & Band Anims** tab, taken in PPSSPP from the
effect showcase song (Today with every effect). Each file is named after the effect (the names in
`scripts/fxchart.js`), as PNG, JPG or WEBP, optionally with the song time in front: `oldfilm.jpg` or `036_oldfilm.jpg`.
The tab finds them by name; an effect without one shows a placeholder. Shape: the PSP's 480 × 272 or a multiple (these
are 1440 × 808); the box is 240 × 136 and crops anything else to fit.

| `012_vortex` | vortex |
| `024_nightvision` | night vision + video lines (file says 042) |
| `036_oldfilm` | black and white + lines, grain, dust, scratches |
| `046_colorfilm` | lines, grain, dust, scratches, in colour |
| `100_tintlines` | tint + video lines |

| `124_blur3` | blur (preset 3) |
| `136_bwflash` | black and white + grain + flash |
